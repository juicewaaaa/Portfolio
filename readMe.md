# Joshua Bandola — Portfolio

AI Automation Specialist & Web Developer portfolio. Plain HTML5, CSS3, and
JavaScript — no frameworks, no build step, ready to deploy as-is.

## Files
- `index.html` — page content, including the Koh-Hee-Hausu case study
- `style.css` — all styling (charcoal / espresso / cream / amber palette)
- `script.js` — interactivity: scroll reveals, expandable experience
  timeline, Koh-Hee-Hausu menu filtering, and a validated contact form
- `resume.pdf` — **add your own résumé file here** with this exact name, or
  update the `href="resume.pdf"` link in `index.html`

## Before you deploy
- Double-check the contact details in `index.html` (email, phone, LinkedIn)
  match what you want public.
- The Koh-Hee-Hausu section is clearly labeled as a concept/portfolio
  project — leave that labeling in place if you keep the section.
- All experience, skills, and certifications are pulled directly from the
  brief you provided. Update wording in `index.html` if anything changes.

## Deploy on GitHub Pages
1. Push these files to a new GitHub repository (root folder or `/docs`).
2. Go to **Settings → Pages**.
3. Under "Build and deployment," choose "Deploy from a branch," pick your
   branch and folder.
4. Your site publishes at `https://<username>.github.io/<repo-name>/`.

## Deploy on Netlify
**Fastest:** drag the folder containing `index.html`, `style.css`, and
`script.js` into [app.netlify.com/drop](https://app.netlify.com/drop) for an
instant live URL.

**Git-based:** push to GitHub, then in Netlify choose "Add new site → Import
an existing project," connect the repo, leave the build command blank, and
set the publish directory to the folder containing `index.html`.
